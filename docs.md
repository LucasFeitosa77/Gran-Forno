# Roteamento

## - CRUD:

### Create 
 Método de criação de objetos
### Read 
 Método de leitura de objetos
### Update
 Método de atualização de objetos
### Delete
 Método de excluir objetos

## - Métodos HTTP:

### GET
 Método HTTP que representa o Read. Serve para ler coisas no site
### POST
 Método HTTP que representa o Create. Serve para crair coisas no site
### PUT
 Método HTTP que representa o Update. Atualiza objetos já existentes no site. Esse em questão atualiza todo o objeto
### PATCH
 Método HTTP que representa o Update. Atualiza objetos já existentes no site. Esse em questão atualiza uma parte do objeto
### DELETE
 Método HTTP que representa o Delete. Deleta objetos já criados no site.


## - Endpoints
 Basicamente são as partes onde o código passa os métodos HTTP

 ## - Rest APIs
 São APIs que seguem o modelo de endpoints com métodos HTTP, assim como feito nesse projeto
